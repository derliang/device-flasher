# device-flasher

## 繁體中文

線上刷韌體網頁：在瀏覽器裡直接**備份、更新、還原**ESP32-C3（人體感應器）與 ESP8266（智慧插座）的韌體。

**目前狀態：建置中。**

- 支援設備（規劃中）：ESP32-C3 人體感應器、ESP8266 智慧插座
- 需求：電腦版 Chrome 或 Edge（需支援 Web Serial），以及 USB 連線
- 全部在你的瀏覽器本機執行，**不會上傳任何資料**
- ⚠️ 備份檔可能含有 Wi-Fi 密碼與金鑰，**請勿分享給他人**

## English

A web page for **backing up, updating and restoring** firmware on ESP32-C3 (presence sensor) and ESP8266 (smart plug) devices, right from your browser.

**Status: under construction.**

- Supported devices (planned): ESP32-C3 presence sensor, ESP8266 smart plug
- Requirements: desktop Chrome or Edge (Web Serial support) and a USB connection
- Everything runs locally in your browser; **nothing is uploaded**
- ⚠️ Backup files may contain Wi-Fi passwords and keys. **Do not share them.**
